# TacticMax Privacy Policy Site

This folder is ready to upload to your GitHub Pages privacy policy repository.

Files:

- `privacy_policy.html` - main privacy policy page
- `index.html` - redirects the site root to `privacy_policy.html`
- `logo.png` - logo file used by the page

Quick upload:

1. Extract the zip.
2. Upload these files to the root of your GitHub Pages repo.
3. Commit the changes.
4. Your existing URL ending in `privacy_policy.html` should keep working.
